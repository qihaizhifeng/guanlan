| Boss | 教会玩家 | 对应魂类经典 |
|---|---|---|
| 韩弩将军 | 基础移动+格挡+观察出招前摇 | 类似《空洞骑士》False Knight |

## 1. 韩弩将军 — 残韩之廊

### 角色设定

> 韩国以弩机闻名天下。韩弩将军不是一个人——他是韩国军工体系的具象化：冷血、精密、机械。他的身体半融于一台青铜弩机中，脊椎被齿轮替代，手指变为扳机。

- **HP**: 300 (教学Boss，较低)
- **阶段数**: 2
- **战斗节奏**: 慢→中
- **定位**: 入门Boss，教会玩家基础战斗

### 场地设计

```
┌──────────────────────────────────────────┐
│                                          │
│    [玩家进入]                             │
│         ↓                                │
│    ┌───── 初始平台 ─────┐                │
│    │                     │                │
│    │     ████ ████       │  ← 弩箭落点   │
│    │                     │                │
│    │    ┌───────┐        │                │
│    │    │ Boss  │        │                │
│    │    │  站立区│        │                │
│    │    └───────┘        │                │
│    │                     │                │
│    └─────────────────────┘                │
│                            ┌──┐           │
│        二层平台 (跳跃可达)  │  │ 烽火台     │
│                           └──┘           │
│                                          │
└──────────────────────────────────────────┘
```

- **场地尺寸**: 约 20格 × 8格（每格 = 1个单位）
- **地面**: 平坦石砖地面，无意外地形
- **二层**: 左右两端有可跳上的小平台（宽2格），用于躲避地面攻击
- **边界**: 左右有墙壁，不可穿过
- **特殊**: Boss 背后有一台巨型弩机装饰（不可交互），战斗中会间歇性射下箭矢落在随机位置

### 阶段一：远程压制 (HP 100% → 50%)

这个阶段重点教会玩家"观察前摇→闪避→找窗口攻击"的基础循环。

#### 攻击模式

| 攻击名 | 前摇表现 | 伤害 | 气力伤害 | 应对方式 | 教学目的 |
|---|---|---|---|---|---|
| **单发劲弩** | Boss 右臂（弩机）发光，0.8s蓄力 | 12 | 8 | 跳跃或冲刺躲避 | 观察发光=危险信号 |
| **三连射** | Boss 后仰，弩机快速闪三下 | 8×3 | 5×3 | 连续冲刺或格挡 | 连续闪避/格挡节奏 |
| **横扫臂击** | Boss 左臂后拉，身体旋转 | 15 | 12 | 下蹲/向后冲刺 | 近身时也需要关注近战 |
| **箭雨（环境）** | 天花板弩机口出现红色瞄准圈 | 10 | 8 | 注意地面红圈移动躲避 | 多线程注意力 |

#### 行动模式

- 起手固定为**单发劲弩**，然后随机从攻击池中选择
- 每次攻击后有 **1.2-1.5s 恢复期**（攻击窗口）
- 如果玩家在 4 秒内未进入近战范围，增加**三连射**的频率
- 每 3 次攻击后，强制触发一次**箭雨**

#### 攻击窗口

- 每次攻击后：约 1.2s，允许 2 次轻击
- 箭雨结束后：约 2.0s，允许 3 次轻击或 1 次重击

#### 阶段转换 (HP ≤ 50%)

Boss 吼叫，弩机装甲碎裂一部分，露出青铜骨架。

### 阶段二：狂暴乱射 (HP 50% → 0%)

速度提升，攻击更难预测。

| 攻击名 | 变化 | 
|---|---|
| 单发劲弩 | 蓄力缩短至 0.5s |
| 三连射 | 增加为**五连射**，弹道略散射 |
| 横扫臂击 | 增加为连续两次横扫 |
| 新招式：**旋转扫射** | Boss 原地旋转，向四面八方散射弩箭，持续1.5s，需要跳跃至二层平台躲避 |

#### 难度曲线

- 第一把 Boss 战，设计目标：**大多数玩家 3-5 次尝试内通过**
- 阶段一让玩家熟悉"观察-闪避-攻击"循环
- 阶段二给予压力但不太过——玩家此时约 5 颗丹药，失误空间充足
- 击败后解锁第一个能力：**车同轨·履（空中冲刺）**

## 2. 赵盾之灵 — 赵地烽原

### 角色设定

> 赵国的灵魂是长城与骑兵。赵盾之灵是一位不存在的将军——他是长平之战 45 万亡灵集体意志的聚合体。没有面孔，只有一面上镂刻着无数哀嚎面孔的青铜盾牌。

- **HP**: 480
- **阶段数**: 3
- **战斗节奏**: 中（防守反击型）
- **定位**: 教会玩家"精准格挡"和"主动创造攻击窗口"

### 场地设计

```
┌──────────────────────────────────────────┐
│                    ↑                     │
│                [玩家进入]                 │
│                    │                     │
│   ┌────────────────┴────────────────┐   │
│   │                                 │   │
│   │   残破军旗  █ █ █ █ █ 残破军旗   │   │
│   │   残破军旗  残破军旗  残破军旗   │   │
│   │                                 │   │
│   │      ┌──────────────┐          │   │
│   │      │   Boss 区域   │          │   │
│   │      │  (中心平台)    │          │   │
│   │      └──────────────┘          │   │
│   │                                 │   │
│   │   ▓▓▓▓▓  石柱  ▓▓▓▓▓ 石柱 ▓▓▓▓ │   │
│   │                                 │   │
│   └─────────────────────────────────┘   │
│                                          │
│      [烽火台在场地外入口处]               │
│                                          │
└──────────────────────────────────────────┘
```

- **场地尺寸**: 约 24格 × 12格
- **地形**: 中心略高（1格台阶），四角有可攀爬的半截石柱
- **军旗**: 装饰性，战斗到后期会燃烧
- **特殊**: 战斗开始时入口处落下铁栅栏封锁

### 阶段一：铜墙铁壁 (HP 100% → 66%)

Boss 举盾缓慢接近玩家，主要考验耐心和精准格挡。

#### 攻击模式

| 攻击名 | 前摇 | 伤害 | 应对 |
|---|---|---|---|
| **盾牌推进** | Boss 低姿态举盾缓慢前进，持续 3s | 接触即 8 | 格挡或绕背 |
| **盾牌猛击** | 盾牌高举，地面出现裂纹效果，1.0s | 22（破盾者 35） | **精准格挡窗口 0.12s**，成功则 Boss 大硬直 |
| **盾缘斩击** | 盾牌侧向挥砍，0.6s | 16 | 格挡或后撤 |
| **呼唤怨灵** | 盾牌重重砸地，0.8s蓄力 | - | 从地面浮现3个怨灵（HP极低，撞到玩家扣5），需要快速清理 |

**关键教学**：盾牌猛击是这场战斗的核心。它的前摇非常明显（盾牌高举，地面裂纹），**精准格挡（0.12s窗口）成功**会让 Boss 进入 2s 的盾牌插入地面的硬直——这时绕到背后可以造成**双倍伤害**。这教会玩家：
1. 魂类格挡的精髓：**高风险高回报**
2. 创造攻击窗口比等待窗口更有效

#### 阶段转换 (HP ≤ 66%)

盾牌碎裂为两半，Boss 发出低沉吼叫，速度提升 20%，增加新招式。

### 阶段二：双持风暴 (HP 66% → 33%)

盾牌分裂为两面手盾，Boss 转为双持攻击模式。

| 攻击名 | 说明 |
|---|---|
| **左右连击** | 左盾→右盾，各 0.4s 间隔，共 2 次 |
| **盾旋风** | Boss 旋转前进，持续 2s，格挡会被连续击退 |
| **盾投** | 投掷一面盾牌，飞行 2s 后返回（可跳过），距离开阔时使用 |
| **猛击（保留）** | 但改为连续两次砸地，范围增大 |

**新战术元素**：二阶段 Boss 会阶段性进入 **"旋风"状态**——这时正确的策略不是格挡，而是**利用冲刺的无敌帧穿过**并绕到背后输出。这教会玩家不同攻击需要不同应对策略。

#### 阶段转换 (HP ≤ 33%)

Boss 停下，将两面盾牌合二为一，盾牌表面浮现一张巨大的哀嚎面孔。场地四角的军旗开始燃烧。

### 阶段三：不灭之盾 (HP 33% → 0%)

整合了前两阶段的全部招式，速度更快，招式链接更无缝。

**新增致命招式：**
- **千魂冲撞** — Boss 化为一道由灵魂构成的冲击波横穿场地，2s 蓄力（盾牌上的面孔睁眼），需要跳跃或精准冲刺躲避
- 这是阶段三的主要威胁，每 3 次普通攻击后触发一次

**击败后**：Boss 跪地，盾牌化为飞灰。玩家获得 **书同文·识**。

## 3. 魏武卒魂·统帅 — 大梁废墟

### 角色设定

> 魏武卒是战国最精锐的重步兵——"衣三属之甲，操十二石之弩，负矢五十个，置戈其上，冠胄带剑，赢三日之粮，日中而趋百里。"统帅之魂被水淹没的瞬间凝固：铠甲锈蚀，水草缠绕，但依然站着。

- **HP**: 650
- **阶段数**: 2
- **战斗节奏**: 慢→极重
- **定位**: 教会玩家"攻其不备"——利用特定招式硬直创造长窗口

### 场地设计

```
┌──────────────────────────────────────────┐
│  水面 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓   │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
│  ▓▓   陆地平台    ▓▓     陆地平台   ▓▓  │
│  ▓▓  ┌──────────┐ ▓▓  ┌──────────┐ ▓▓  │
│  ▓▓  │   Boss    │ ▓▓  │ (水的)   │ ▓▓  │
│  ▓▓  │   初始位置 │ ▓▓  │ 高处平台 │ ▓▓  │
│  ▓▓  └──────────┘ ▓▓  └──────────┘ ▓▓  │
│  ▓▓                ▓▓                ▓▓  │
│  ▓▓   陆地平台    ▓▓   陆地平台     ▓▓  │
│  ▓▓  ┌──────────┐ ▓▓  ┌──────────┐ ▓▓  │
│  ▓▓  │  可破坏   │ ▓▓  │ 可破坏   │ ▓▓  │
│  ▓▓  │   支柱     │ ▓▓  │  支柱    │ ▓▓  │
│  ▓▓  └──────────┘ ▓▓  └──────────┘ ▓▓  │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
│  水面 (接触扣 3/s，减速 50%)            │
│                                          │
│   [入口]   烽火台在入口右侧              │
└──────────────────────────────────────────┘
```

- **场地尺寸**: 约 20格 × 14格
- **水面**: 场地四周和中间有积水区（深1格），进入后移动减速 50%，每秒扣 3 气血
- **平台**: 四个高出水面的平台（2×3格），其中两个有可破坏的石柱
- **节奏**: 需要在对峙中兼顾站位——不要让自己背水

### Boss 特性

魏武卒统帅是游戏目前最重的敌人：
- 移动极慢（常规走路比玩家步行慢）
- 攻击伤害极高，但前摇极长
- 正面几乎不可破——**所有正面攻击伤害减半**
- 弱点：背后和攻击硬直时

### 阶段一：铜墙铁壁 (HP 100% → 45%)

**核心机制——"架势值"**：Boss 有一层隐藏的架势值（200点），每次被击中（包括格挡 Boss 的攻击）都会减少。架势值归零时，Boss 单膝跪地 3s。这 3s 是主要输出窗口。

| 攻击名 | 前摇 | 伤害 | 应对 |
|---|---|---|---|
| **戈矛横斩** | 重甲后摆，2.0s蓄力，青铜戈发出低鸣 | 35 | 格挡（仍受 10 伤害）或绕背——这是主要攻击窗口 |
| **践踏** | 抬脚，地面震动效果，1.2s | 20 | 跳跃或远离——生成小范围冲击波 |
| **盾墙推进** | 举盾缓慢前移 4s，碰到扣 10 | 10/接触 | 绕背攻击——Boss 转向很慢 |
| **水波斩** | 戈矛砸向水面，周身水花飞溅，1.5s | 25 | 跳上平台躲避——水面传导伤害 |

**战术核心**：不要正面硬拼。利用 Boss 转向慢的特点绕背，在 Boss 攻击硬直时输出。戈矛横斩是最大的攻击窗口——**绕到背后可以打出 3-4 次轻击**。

架势值归零的处决场景：玩家绕到跪地的 Boss 背后，执行特殊处决动画——一剑刺入铠甲缝隙。

#### 阶段转换 (HP ≤ 45%)

Boss 仰天怒吼，震碎半身铠甲，露出锈蚀的身体。移动速度提升30%，增加新招式。

### 阶段二：狂战士 (HP 45% → 0%)

Boss 放弃防御，转为纯攻击姿态。

| 新增招式 | 说明 |
|---|---|
| **二段横斩** | 戈矛横斩 + 立即跟进的回身斩，需要闪避两次 |
| **跳劈** | Boss 跃起，目标锁定玩家位置落地，落地冲击波范围 3 格 |
| **水龙卷** | Boss 原地旋转戈矛，卷起周围水流形成涡旋，吸附玩家并持续扣血 |

**新机制——场景破坏**：跳劈会击碎平台上的可破坏支柱。支柱破坏后，该平台沉入水中消失，**永久缩小可站立区域**。这迫使玩家不断调整站位。

**击败后**：Boss 沉入水中，最后一只手缓缓没入水面。玩家获得 **衡同量·衡（重击冲击波）**。

## 4. 楚巫祭·灵均 — 楚泽冥域

### 角色设定

> "灵均"取自屈原的字。楚巫祭不是屈原——她是一种楚国巫文化与屈原诗歌精神融合的存在。她的身体是半透明的，内部流转着磷光，发间缠绕着水草，声音像是从水中传来。

- **HP**: 520
- **阶段数**: 3
- **战斗节奏**: 慢→弹幕→混乱
- **定位**: 教会玩家"弹幕规避"和"优先级判断"

```
│  ░░ = 毒沼 (扣 5/s)                      │
│  ██ = 立足平台 (4×1)                    │
│  Boss 在空中浮动                          │
└──────────────────────────────────────────┘
```

- **场地尺寸**: 约 22格 × 12格
- **毒沼**: 占地面 60%，玩家必须不断在平台间移动
- **平台**: 9 个窄平台（4×1 格），成 3×3 网格分布，间距约 2-3 格
- **Boss 位置**: Boss 在空中漂浮（约地面以上 4 格），可自由移动
- **特殊**: 每 30s 毒沼水位变化一次，淹没部分平台，持续 10s

### Boss 特性

- 楚巫祭几乎不落地，始终在空中漂浮
- 玩家的近战攻击范围通常打不到她——需要利用**跳跃攻击**和**平台跳**来接近
- 这是一个"节奏控制"型 Boss：玩家必须在管理站位（不被毒沼淹没）的同时处理弹幕

### 阶段一：幽歌 (HP 100% → 66%)

Boss 缓慢浮游，以单发弹幕为主。

| 攻击名 | 说明 |
|---|---|
| **磷光弹** | 发射一个缓慢追踪玩家的光球，飞行速度中等，可被攻击打散 |
| **水草缠绕** | 从毒沼中伸出触手，定身玩家 1.5s（可挣脱），需要 QTE 按键或快速连点 |
| **鬼火圈** | 在玩家周围生成一圈 6 个鬼火，0.5s 后向中心收缩 |
| **吟唱召唤** | Boss 吟唱 2s，召唤 2 个楚巫幻影（仅近战，低血量） |

**关键设计**：磷光弹的水草缠绕的组合是这个阶段的杀手——被水草定身后磷光弹会命中。玩家需要学会**优先级判断**：先打散磷光弹，再处理水草，最后输出 Boss。

#### 阶段转换 (HP ≤ 66%)

Boss 停止移动，身体发出刺目的绿光，毒沼水位暴涨（淹没 2 个平台 12s）。

### 阶段二：九歌 (HP 66% → 33%)

弹幕密度翻倍，Boss 开始吟唱《九歌》残篇（背景声中出现模糊的楚辞吟唱）。

| 新增招式 | 说明 |
|---|---|
| **双弹追击** | 同时发射两个磷光弹，交替追踪 |
| **东皇太一** | Boss 召唤一个巨大的太阳般的光球，缓慢扫过场地，占据半屏宽度 |
| **湘夫人泪** | 从天而降的雨滴状弹幕，持续 4s，地面有落点预警 |
| **水毒柱** | 毒沼中随机位置升起水柱，0.8s 预警 |

**教学重点**：这个阶段要求玩家在**移动中规划路线**——光球扫过来的方向决定了你必须往哪边移动，而雨滴弹幕和毒柱迫使你在移动中精准跳跃到安全平台。

#### 阶段转换 (HP ≤ 33%)

Boss 长发散开，身体化为纯粹的半透明磷光形态，场地进入"暗夜"状态（光照降低，弹幕轨迹更加明亮）。

### 阶段三：离骚 (HP 33% → 0%)

**视觉特征**：屏幕变暗，只有磷光弹幕照明，Boss 时隐时现。

**新机制——"诗篇"**：Boss 每 15s 吟唱一句《离骚》诗句，吟唱期间无敌，诗句内容决定接下来的弹幕模式：

| 诗句 | 触发的弹幕 |
|---|---|
| "路漫漫其修远兮" | 长条形的连续光柱从一端扫到另一端 |
| "吾将上下而求索" | 弹幕从上下左右四个方向交替发射 |
| "长太息以掩涕兮" | 全屏缓慢落下的泪滴弹幕，持续 5s |
| "虽九死其犹未悔" | Boss 瞬移三次，每次出现释放一圈弹幕 |

**打法**：诗句吟唱时集中注意力观察——不同诗句需要不同的躲法。这是 Boss 的出招窗口也是唯一能输出的时机（吟唱结束后的短暂停顿）。

**击败后**：Boss 缓缓落地，磷光熄灭，留下一片枯荷叶。玩家获得 **修驰道·行（滑铲加速）**。

## 5. 荆轲执念 — 燕云冰窟

### 角色设定

> 荆轲——中国历史上最著名的刺客。他不是来杀你的。他是那个未完成的刺秦动作本身，被帝陵困住的"图穷匕见"的那一瞬间。他一遍遍地冲刺，刺向虚空，永远刺不中早已不存在的目标。

- **HP**: 400（低血量，但每次攻击只能打 1-2 下）
- **阶段数**: 3
- **战斗节奏**: 极快
- **定位**: 速度型 Boss，压迫感型战斗。教会玩家"预判"和"越级反应"

### 场地设计

```
┌──────────────────────────────────────────┐
│                                          │
│  ▓▓        ▓▓        ▓▓        ▓▓      │
│       ▓▓                  ▓▓            │
│   ▓▓       ▓▓        ▓▓        ▓▓      │
│                                          │
│      ▓▓        ▓▓        ▓▓             │
│           ▓▓             ▓▓             │
│   ▓▓       ▓▓        ▓▓       ▓▓       │
│                                          │
│     冰柱分布：可摧毁，摧毁后 10s 再生    │
│     ▓▓ = 冰柱（直径 1 格，遮挡视线）      │
│                                          │
│     [入口]     烽火台在入口左侧          │
└──────────────────────────────────────────┘
```

- **场地尺寸**: 约 24格 × 16格（目前最大的场地）
- **冰柱**: 散落的立柱（直径1格），可以遮挡视线，可被攻击摧毁，10s 后再生
- **冰面**: 部分区域有薄冰层，踩上去 0.5s 后碎裂（掉入下方小空间）
- **视觉**: 苍白、寒冷、空无一物——除了荆轲的残影

### Boss 特性

荆轲是游戏中最快的敌人。他的战斗逻辑是 **Hit & Run**——永远不和你正面对峙。

- 大部分时间处于**不可锁定**的冲刺状态
- 每次现身后只做一次攻击就立刻消失
- 攻击间隔极短（1.0-1.5s）
- 但攻击后的硬直也很短（0.3-0.5s）

**核心设计哲学**："荆轲战不是一场战斗，是一次刺杀演练。你是目标，他是刺客。你要学会在绝境中捕捉那唯一的反击机会。"

### 阶段一：图穷 (HP 100% → 66%)

| 攻击名 | 说明 |
|---|---|
| **正面突刺** | 从正面冲刺而来，速度极快（0.3s），有 0.1s 的匕首反光提示 |
| **侧影突袭** | 瞬移到玩家侧面（左侧或右侧），1.0s 后突刺 |
| **空翻背刺** | 从玩家头顶翻过，落地后立即刺向背部 |
| **冰面滑行** | 在冰面上滑行，接近玩家时跃起下刺 |

**应对方式**：每招都有大致 0.2-0.3s 的反应窗口。需要玩家根据起手动作预判。

**关键技巧**：荆轲冲刺时**可以格挡**——精准格挡可以触发一次较长的硬直（1.0s），这是主要输出窗口。但窗口极短。

**教学意图**：这不是一个你可以靠反应来打的 Boss——至少前几次不行。你需要**死出模式**，然后**预判**。

#### 阶段转换 (HP ≤ 66%)

荆轲停在场中央，将匕首插入冰面——地面裂开，部分区域塌陷，缩小可站立面积。

### 阶段二：匕见 (HP 66% → 33%)

速度进一步加快，新增更致命的招式。

| 新增招式 | 说明 |
|---|---|
| **双影刺杀** | 分裂为两个残影，从左右两侧同时攻击——只能躲不能格挡 |
| **冰遁** | 钻入冰面消失，3s 后在玩家脚下破冰而出（地面先出现裂纹预警） |
| **连刺** | 连续三次冲刺——左→右→上（跳跃躲避第三次） |

**教学重点**：这个阶段引入了"不可格挡的攻击"——双影刺杀必须用冲刺无敌帧穿越。玩家必须学会**分辨哪些攻击可以格挡、哪些必须闪避**——这和魂类的核心决策一致。

#### 阶段转换 (HP ≤ 33%)

Boss 停止移动，将匕首指向天空。一道光柱落下，整个场地开始飘雪。荆轲的残影变为纯白，速度达到峰值。

### 阶段三：易水寒 (HP 33% → 0%)

> "风萧萧兮易水寒，壮士一去兮不复还。"

这是荆轲最致命也最悲壮的一段。他的每个动作都更快、更致命、更难以预测。但他的匕首也开始**碎裂**——每次攻击后匕首碎片掉落在地，发出清脆的声响。

**新机制——"碎片"**：每次荆轲攻击后，地面上会留下一块匕首碎片（持续发光 5s）。收集碎片可以**回复 5 气力**，同时会**减慢荆轲下一次攻击 0.1s 的前摇**（因为匕首变短了）。收集 5 块碎片后进入一次**5s 的慢动作状态**——这是唯一的长时间输出窗口。

**设计意图**：这个机制把绝望感转化为策略感——"碎片"奖励玩家的冒险行为（收集需要在荆轲攻击的间隙去捡），同时也给了玩家一个明确的"反击号角"时刻。

**击败后**：荆轲的最后一击——他冲向玩家，然后在命中前 0.1s 化为冰尘消散。最后一枚匕首碎片落在地上，上面刻着一行小字："图已穷，匕不见。" 玩家获得 **铸铜符·令（分身召唤）**。

## 6. 稷下魂·辩论 — 齐道幻境

### 角色设定

> 齐国的灵魂是稷下学宫——战国时代最自由的思想市场。稷下魂不是一个人，是所有曾在学宫中辩论的思想家们的集合。他没有固定形态——有时是竹简堆成的人形，有时是飞散的墨迹。他的"辩论"不是用语言，是用**规则**。

- **HP**: 380
- **阶段数**: 4（核心：换规则）
- **战斗节奏**: 变化不定
- **定位**: 智力型 Boss。教会玩家"适应规则变化"

### 场地设计

```
┌──────────────────────────────────────────┐
│                                          │
│    ┌─────┐                  ┌─────┐     │
│    │书简堆│                  │书简堆│     │
│    └─────┘                  └─────┘     │
│                                          │
│          ┌──────────────────┐            │
│          │                  │            │
│          │   擂台中心区域    │            │
│          │   (主要战斗区)   │            │
│          │                  │            │
│          └──────────────────┘            │
│                                          │
│    ┌─────┐                  ┌─────┐     │
│    │墨池  │                  │墨池  │     │
│    └─────┘                  └─────┘     │
│                                          │
│    四周的竹简堆和墨池会阶段性地伸出"规则碑文"         │
│    触碰后清除当前规则效果                           │
└──────────────────────────────────────────┘
```

- **场地尺寸**: 约 18格 × 12格
- **擂台**: 平坦的圆形或方形区域
- **书简堆**: 散落在四角的场景物件，每阶段转换时激活一个
- **墨池**: 踏入后短暂减速但可回复少量气力
- **天幕**: 场地正上方有一幅巨大展开的竹简，**实时显示当前规则**

### 核心机制——"规则切换"

稷下魂的战斗核心是一个循环：

```
规则A (30s) → 规则B (30s) → 规则C (30s) → 规则A (30s) → ...
```

每次切换前，一个巨大的篆书文字出现在屏幕中央（如"反"、"衡"、"兼"），场地四角的书简堆之一会发光。玩家可以**触碰发光的书简堆来提前结束当前规则**（同时清除此规则对应的负面效果，但也会失去该规则下对玩家的增益）。这是一个策略抉择。

### Boss 的攻击模式

稷下魂本身的攻击并不强——它只有 3 种基础招式：

| 基础攻击 | 伤害 | 说明 |
|---|---|---|
| **墨弹** | 8 | 发射一枚缓慢飞行的墨水球 |
| **书页飞刀** | 10 | 掷出 3 片飞旋的竹简 |
| **踏墨** | 12 | 踩踏墨迹形成小范围冲击波 |

它真正的威胁来自**规则本身**。

### 规则表

| 规则 | 名称 | 玩家影响 | 敌人影响 | 设计意图 |
|---|---|---|---|---|
| **A: 法家·严刑** | "法" | 轻击伤害+50%，但受击伤害也+50% | 无变化 | 高风险高回报——打得快死得快 |
| **B: 道家·无为** | "反" | 攻击不消耗气力，但气力恢复停止 | Boss 移动速度-30% | 放开打但要注意气力不会自然恢复 |
| **C: 墨家·兼爱** | "兼" | 剑气变为双倍（攻击判定范围增大），但丹药治疗效果减半 | Boss 会召唤低血量的纸兵 | 范围优势换续航劣势 |
| **D: 名家·诡辩** | "辩" | 攻击和受击时，有30%概率交换双方位置（瞬移） | 无变化 | 完全的混乱状态——位置不断变化 |
| **E: 阴阳家·五行** | "行" | 场地出现五行轮转——每10s切换一次属性伤害类型 | Boss 获得当前属性抗性但弱于相克属性 | 需要玩家发现相克关系 |
| **F: 儒家·礼乐** | "礼" | 无法冲刺，但格挡减伤提升至90% | Boss 攻击频率-20% | 防守姿态——龟缩但安全 |

### 战斗流程

**阶段一** (HP 100% → 75%)：规则 A → B → C，每个 40s，节奏较慢

**阶段二** (HP 75% → 50%)：规则 A → B → C → D，每个 30s，增加名家诡辩的混乱

**阶段三** (HP 50% → 25%)：规则 B → D → E，每个 25s，加入阴阳家五行

**阶段四** (HP 25% → 0%)：规则 C → E → F，每个 20s——最后的儒家礼乐阶段意味着玩家被逼迫在最保守的规则下完成最后的输出

**击败后**：书简散落一地。一个模糊的声音说："百家之言，终究要被统一。" 玩家获得 **同度量·合（归一状态）**。

## 7. 嬴政·肇始 — 帝心

### 角色设定

> 在陵墓的最深处，在所有六层记忆的交汇点，始皇帝的灵魂坐在一张不存在的王座上。他不是怪物。他看起来不像史书里的暴君——他只是一个疲惫的中年男子，穿着最朴素的黑色深衣，手中握着一卷竹简。

> 他的战斗不是要杀你。他是要**证明给你看**——统一是对的，撕碎六国是对的，焚书坑儒是对的。每一阶段他会用一种前六国的方式战斗，仿佛在说："看，我没杀了他们，我只是把他们变成了我的一部分。"

- **HP**: 三个阶段的独立血条（800 + 600 + 400 = 1800）
- **阶段数**: 3（每阶段独立血条，阶段转换时满血+换机制）
- **战斗节奏**: 慢→全融合→哲学
- **定位**: 最终考验——玩家必须掌握全部前六 Boss 所学

### 场地设计

```
┌──────────────────────────────────────────┐
│                                          │
│    第一阶段场地：青铜王座大厅             │
│    ┌────────────────────────────────┐    │
│    │                                │    │
│    │          王座                  │    │
│    │        【凹】                   │    │
│    │     ┌─────────────┐            │    │
│    │     │  主战斗区域   │            │    │
│    │     │  (石砖地面)  │            │    │
│    │     └─────────────┘            │    │
│    │                                │    │
│    └────────────────────────────────┘    │
│                                          │
│    第二阶段场地：七国碎片                │
│    空间分 7 块——每块对应一国风格         │
│    每 15s 切换一次为随机一国              │
│    会继承该国的环境特征（毒沼/冰面等）    │
│                                          │
│    第三阶段场地：一片纯白虚空             │
│    没有任何边界，没有地面——               │
│    只有一个不断变化的帝国舆图在脚下流转    │
│    是"统一"这个概念本身的具象化           │
└──────────────────────────────────────────┘
```

### 阶段一：王座之间 (HP: 800)

嬴政坐在王座上，缓慢起身。他使用的招式和**韩弩将军**同源——远程压制，但更加精妙。

**攻击模式**：远距离金色光矢（秦弩的升华），飞行轨迹更复杂。

| 攻击名 | 说明 |
|---|---|
| **一统劲弩** | 金色光矢，追踪玩家，可格挡 |
| **五矢连珠** | 5 枚光矢呈梅花形射出 |
| **统一之敕** | 地面出现篆书文字区域，对应区域 2s 后爆炸 |
| **王座践踏** | 嬴政踩踏地面，全场地冲击波（需跳跃） |

**窗口**：每次攻击后 0.8s，可打 2 轻击。

#### 阶段转换 (HP ≤ 0)

王座碎裂，空间扭曲。嬴政的声音："你学得很快。但现在才是真正的考试。"

### 阶段二：七国熔炉 (HP: 600)

场地变为 7 块碎片，每块对应一国的环境特征。每 15s 随机切换当前"有效"区域（站在有效区域外的玩家持续扣血）。

嬴政的招式现在**轮流使用六个 Boss 的变体**：

| 轮次 | 使用的风格 | 速度倍率 | 特殊要素 |
|---|---|---|---|
| 第1轮 | 韩弩将军（远程） | 1.2x | 箭矢带追踪 |
| 第2轮 | 赵盾之灵（防守反击） | 1.3x | 格挡后释放冲击波 |
| 第3轮 | 魏武卒魂（重击） | 1.0x | 范围增大 |
| 第4轮 | 楚巫祭（弹幕） | 1.4x | 弹幕密度翻倍 |
| 第5轮 | 荆轲执念（速度） | 1.3x | 隐身时间更长 |
| 第6轮 | 稷下魂（规则） | 1.0x | 规则变化极快（8s换一次） |
| 第7轮 | 全部融合 | 1.5x | 混用多种风格 |

**关键设计**：这阶段测试玩家对六个 Boss 每个招式的记忆——不是靠蛮力，是靠经验。

#### 阶段转换 (HP ≤ 0)

空间崩塌。一切变白。嬴政的声音变得温和："你走过了六国的路。那么，你理解了吗？"

### 阶段三：太一之辩 (HP: 400)

> 这不是一场战斗。这是一场对话，以剑为语言。

**核心机制**：这个阶段**不需要将嬴政的 HP 打到 0**。而是通过特定行为触发隐藏计量：

- 每次**精准格挡**嬴政的攻击 → +10% "理解度"
- 每次**在嬴政攻击后立即使用同样招式攻击** → +15% "理解度"
- **不攻击嬴政，连续格挡 5 次** → +20% "理解度"
- 站在嬴政面前什么都不做，持续 3s → +5% "理解度"
- 主动攻击 → "理解度"不变

当 "理解度" > 80% → 触发 **结局二：不朽者**
当 "理解度" < 40% → 嬴政 HP 归零 → 触发 **结局一：统一者**

#### 阶段三攻击模式（不致命——更像一种沉重的舞蹈）

嬴政的攻击速度变得极慢，但每一击都沉重而优美。他的招式全是前六个 Boss 的动作，但仿佛慢动作回放——这不是在攻击你，他是在"演示"给他自己看。

| 动作 | 类似 | 前摇时长 | 格挡难度 |
|---|---|---|---|
| 金色弩矢 | 韩弩将军 | 2.0s（极慢） | 极简单 |
| 回忆之盾 | 赵盾之灵 | 2.5s | 简单 |
| 沉重戈击 | 魏武卒魂 | 3.0s | 简单 |
| 磷光叹息 | 楚巫祭 | 2.0s | 中等 |
| 迟来的刺 | 荆轲执念 | 1.5s | 中等 |
| 规则铭刻 | 稷下魂 | 3.0s | 简单 |

每次格挡或闪避成功，会出现该招式对应国家的鬼魂幻影——它们朝着嬴政鞠躬，然后消散。

**隐藏机制——如果在"迟来的刺"时不做任何操作不闪避不格挡**：荆轲的幻影会完整显现，匕首停在嬴政喉咙前 0.1 寸。嬴政第一次露出不是疲惫的表情——而是悲伤。"他本可以……" 此时 +30% 理解度（剧情触发）。

#### 击败后

**结局一**：嬴政消散。陵墓开始崩塌。玩家独自走向白光。

**结局二**：嬴政的剑垂下来。他看了你很久。"你懂了。"他坐下，拿起笔（一支竹简凭空出现），开始书写。你坐到他身边。画面渐暗。外面不知道是秦朝第几年，但有人还在写历史。

### 非线性的难度控制

虽然 Boss 本身的难度递增，但玩家到达不同 Boss 时的**路径长度和升级空间**也管控了实际难度：

- **韩弩将军**: 残韩之廊约 15-20 分钟到达，玩家升级空间小（约 1-2 次烽火台升级）
- **赵盾之灵**: 赵地烽原约 20-30 分钟到达，可升级 2-3 次气血
- **魏武卒魂**: 大梁废墟约 30-40 分钟到达，可升级 3-4 次
- **楚巫祭**: 楚泽冥域约 40-50 分钟到达，可升级 4-5 次
- **荆轲执念**: 燕云冰窟约 30-40 分钟到达，路线中有大量隐藏可收集
- **稷下魂**: 齐道幻境约 20-30 分钟到达，但路线解谜密集，升级较少
- **嬴政**: 全收集玩家 vs. 速通玩家的难度差异在此体现

这种设计确保了：
1. 新手在韩弩将军处有充足容错空间
2. 中间段玩家通过探索获得了足够的提升来应对难度爬升
3. 最终 Boss 对装备和能力的检验既公平又有区分度
