# 秦殇 — 游戏设计文档 (GDD)

> **版本**: v1.0
> **引擎**: Unity 2D (URP)
> **类型**: 2D 类魂 × 类银河城（Metroidvania）
> **目标平台**: PC (Steam)
> **风格参考**: Hollow Knight, Nine Sols, Blasphemous

---

## 一、核心愿景

### 一句话定义

> 一款以秦始皇统一六国为背景的 2D 类魂·类银河城游戏。玩家扮演乱世亡魂，在帝陵的幽冥映射中穿行，亲历七国覆灭的创痛，直面那些被历史碾过的面孔。

### 设计目标

1. **战斗手感第一** — 精确、有节奏、低容错，以空洞骑士的操作精度为基准
2. **环境叙事驱动** — 故事不靠对话，靠地图、敌人、物品描述和场景本身讲述
3. **文化还原不是装饰，是游戏机制** — 统一文字/度量衡/车轨是能力解锁；法家/儒家/墨家的思想冲突是关卡设计和 Boss 行为的底层逻辑
4. **七国各有性格** — 每一层陵墓不仅视觉不同，敌人的战斗风格、陷阱类型、解谜方式都源自对应国家的历史特征

### 玩家代入

玩家不是嬴政。玩家是**一个被遗忘的亡魂**——死于统一战争中的无名者。在帝陵中苏醒，不记得自己是谁，只记得"统一"带来的痛。

## 二、故事与世界设定

### 世界观

秦始皇陵——"以水银为百川江河大海，上具天文，下具地理。"

游戏中的陵墓不是真实陵墓，而是**逝者意识的投影世界**——所有被统一战争吞噬的灵魂，其记忆、执念和痛苦在此交织成形。

- 陵墓的**每一层对应一个被征服的战国**（韩→赵→魏→楚→燕→齐）
- 征服的顺序也是**深入陵墓的顺序**，越往下越接近核心
- **陵墓核心**沉睡着嬴政的灵魂——他是整个世界的"病因"

### 叙事方式（纯环境叙事）

游戏没有传统对话。玩家通过以下方式拼凑故事：

1. **壁画与铭文** — 秦代风格壁画描绘灭国战役
2. **鬼魂残响** — 击败敌人后出现幻影，重演生前最后时刻
3. **物品描述** — 每件物品有简短的文本
4. **Boss 战** — 阶段转换对应历史事件转折
5. **场景本身** — 堆满竹简的房间、倾覆的礼器、断裂的驰道——都在说话

### 时间线（环境叙事暗线）

| 历史事件 | 游戏中的呈现方式 |
|---|---|
| 前230年 秦灭韩 | 残韩之廊 — 机关遍布，韩国以弩机/冶金闻名 |
| 前228年 秦灭赵 | 赵地烽原 — 开阔战场，胡服骑射的残影，长平怨灵 |
| 前225年 秦灭魏 | 大梁废墟 — 水攻痕迹，城墙裂开，积水区 |
| 前223年 秦灭楚 | 楚泽冥域 — 沼泽巫术，屈原残魂 |
| 前222年 秦灭燕 | 燕云冰窟 — 荆轲刺秦执念凝固成冰 |
| 前221年 秦灭齐 | 齐道幻境 — 稷下学宫废墟，思想迷宫 |
| 前221年统一/前210年驾崩 | 帝心 — 最终 confrontation |

## 三、核心玩法循环

### 宏观循环

探索陵墓 → 遭遇敌人/陷阱 → 激活烽火台(存档)
    ↑                                   ↓
获得新能力 ← 击败区域Boss ← 探索更深层
    ↓
解锁之前到不了的区域(类银河城回溯)

### 单次探索循环

烽火台(回满状态) → 探索未知通道 → 小兵战/陷阱机关 → 发现捷径/隐藏房间 → 精英敌人/Boss → 下一个烽火台

### Boss 战微循环（类魂核心）

观察模式 → 等待出招后窗 → 闪避/格挡 → 攻击窗口 → 拉开距离恢复气力 → 重复至阶段转换 → 重新学习模式 → 处决/击杀

## 四、战斗系统

### 4.1 玩家属性

| 属性 | 初始值 | 说明 |
|---|---|---|
| 气血 (HP) | 80 | 归零即死亡 |
| 气力 (QI) | 100 | 攻击/格挡/冲刺消耗，自动恢复 |
| 攻击力 | 15/30 | 轻击/重击基础伤害 |
| 气力恢复速度 | 25/s | 停止消耗后开始恢复 |
| 丹药 | 3 | 每次恢复35HP，烽火台补充 |

### 4.2 玩家动作

| 动作 | 按键 | 气力消耗 | 说明 |
|---|---|---|---|
| 轻击 | Z / 左键 | 12 | 快(0.25s)、可连击3次 |
| 重击 | X / 右键 | 30 | 慢(0.6s)、击退、可蓄力 |
| 格挡 | C / Shift | 成功扣5 | 正面减伤70%，减速移动 |
| 精准格挡 | 命中前0.15s按格挡 | 0 | 弹反，硬直1.2s |
| 冲刺 | Space / Shift | 15 | 0.3s无敌帧 |
| 跳跃 | W / Space(空中) | 0 | 基础跳跃 |
| 下落攻击 | 空中+下+攻击 | 20 | 1.5x伤害 |
| 使用丹药 | E / Q | 0 | 2s读条可被打断 |
| 处决 | 硬直敌人+攻击 | 0 | 固定伤害，回复气血 |

### 4.3 战斗机制细则

**硬直**: 轻击0.3s，重击0.6s。Boss有"韧性"属性。

**受击反馈**: hit-stop + 屏幕震动 + 闪烁。玩家0.15s，敌人0.1s，Boss 0.05s。

**无敌帧**: 冲刺前0.3s，受击后1.0s，起身0.5s。

### 4.4 死亡与惩罚

- 气血归零 → 最近烽火台复活
- **失去所有"阴钱"（货币）**，保留装备和升级
- 敌人全部重置
- 可在死亡地点回收一次阴钱（捡魂机制）

## 六、七国区域详细设计

### 6.1 残韩之廊 — 入门区域

韩国，七国最弱最先被灭。以弩机/冶金闻名。法家发源地。

- **地形**: 狭窄甬道，青铜铆接机关门
- **色调**: 深灰、青铜绿、暗红
- **敌人**: 韩弩兵(远程)、腐化卫兵(近战)
- **精英**: 机关工(布置地面陷阱)
- **Boss**: 韩弩将军 — 巨型弩机装甲武将
- **能力**: 车同轨·履(空中冲刺)
- **教学功能**: 基础移动、战斗、陷阱规避、烽火台

### 6.2 赵地烽原 — 第二区域

赵国，胡服骑射改革。长平之战45万赵军被坑杀。

- **地形**: 开阔墓室群，断桥，演兵场废墟
- **色调**: 赭石、土黄、血色天幕
- **敌人**: 赵骑兵残影(快速突刺)、长平怨魂(高伤)
- **精英**: 胡服弓骑(移动射击)
- **Boss**: 赵盾之灵 — 盾阵将军，防守反击转狂暴冲锋
- **能力**: 书同文·识(解读碑文)

### 6.3 大梁废墟 — 第三区域

魏国，魏武卒精锐，水淹大梁城。

- **地形**: 半淹城塞，上层干燥下层积水
- **色调**: 墨绿、灰蓝、锈色
- **敌人**: 魏武卒残灵(重甲)、水鬼(水中突袭)
- **精英**: 城门卫魂(大盾正面不可破)
- **Boss**: 魏武卒魂·统帅 — 重甲长戈，地形破坏
- **能力**: 衡同量·衡(冲击波)

### 6.4 楚泽冥域 — 第四区域

楚国，地域最大，巫风盛行，屈原投江。

- **地形**: 地下溶洞+沼泽，毒雾区
- **色调**: 紫黑、幽绿、磷光蓝
- **敌人**: 楚巫祭(远程法术)、阴兵(瞬移)
- **精英**: 巨蟒魂(多段移动Boss)
- **Boss**: 楚巫祭·灵均 — 融合屈原意象的法系Boss
- **能力**: 修驰道·行(滑铲加速)

### 6.5 燕云冰窟 — 第五区域

燕国，苦寒之地，荆轲刺秦。

- **地形**: 冰封洞穴，冰面滑行，冰锥坠落
- **色调**: 冰蓝、白、深灰
- **敌人**: 燕甲残兵(高伤慢速)、冰晶(环境)
- **精英**: 刺客残影(快进快出)
- **Boss**: 荆轲执念 — 高速刺杀，图穷匕见
- **能力**: 铸铜符·令(分身召唤)

### 6.6 齐道幻境 — 第六区域

齐国，最晚被灭。稷下学宫思想开放。

- **地形**: 迷宫式学者废墟，传送门，错觉谜题
- **色调**: 苍白、墨色、淡金
- **敌人**: 稷下学魂(施法者)、纸兵(召唤)
- **精英**: 论战者(解谜式战斗)
- **Boss**: 稷下魂·辩论 — 规则每30秒变换
- **能力**: 同度量·合(归一状态)

### 6.7 帝心 — 最终区域

秦统一 + 始皇驾崩。七国碎片交织。

- **地形**: 碎片拼接扭曲空间，水银河
- **色调**: 金、黑、水银白
- **最终Boss**: 嬴政·肇始 — 使用前六国Boss能力，最终形态为疲惫孤独的灵魂
- **结局**: 见结局章节

## 九、美术风格指南

### 核心理念: "简墨重彩" — 极简剪影承载厚重历史

**色板**: 黑(#0a0a0a)、朱红(#8b0000)、青铜绿(#4a7c59)、土黄(#8b7355)、冰蓝(#6fa8dc)、墨色(#1a1a2e)、水银白(#d0d0d0)、金(#d4a017)

**角色**: 黑色剪影轮廓 + 青铜剑亮色边缘，肩甲轮廓暗示秦甲。敌人在此基础上加区域特征（尖盔、旗冠、巫冠等）。

**UI**: 朱红篆书印章式血条、"气"、"血"、"丹"字样、竹简背包、帛书地图、墨迹渗透死亡画面。

## 十、音频方向

**音乐**: 古琴/编钟/箫/埙/大鼓为音色基底，大量混响/延迟营造幽冥感。每区域有独特音色（残韩之廊机械节奏、楚泽冥域巫祭吟唱、燕云冰窟风啸冰裂）。

**SFX**: 青铜剑击清脆声、格挡金属撞击、气力呼吸声、压抑受伤闷哼、丹药瓷瓶声。

## 十一、结局

**结局一"统一者"**: 击败最终Boss。接受统一已发生。走出陵墓面对一片苍白的空无——但"记得他们，那就够了。"

**结局二"不朽者"**: 击败所有六国Boss + 收集全部记忆碎片 + 最终战不攻击嬴政。理解了他。接过统一的负担，坐下来继续书写那部永远不会完成的史书。

## 十二、技术架构（Unity 2D）

### 核心设计模式

1. **GameManager (Singleton)** — 全局游戏状态管理
2. **Component-based Player** — 各功能拆分独立组件
3. **State Machine for AI** — 所有敌人/Boss使用状态机
4. **ScriptableObject 数据配置** — 武器/敌人/护符数据
5. **Event-driven 架构** — 核心事件通过event/Action广播

### 渲染方案

- **URP 2D Renderer** + 2D Lighting
- 点光源模拟火炬/鬼火
- 后处理: 暗角、颜色校正、Bloom（重要交互物）
- 粒子系统: 攻击特效、毒雾、冰雪

### 输入

Unity Input System: WASD移动、鼠标左键/Z轻击、右键/X重击、Shift/C格挡、空格冲刺、E/Q丹药、F交互、Tab地图、Esc暂停。
