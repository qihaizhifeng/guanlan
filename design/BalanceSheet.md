## 八、伤害公式

### 基础伤害

```
最终伤害 = 基础攻击 × 武器攻击倍率 × (1 + 护符攻击加成%) 
         × 部位倍率 - 目标防御 × (1 - 破甲%)
```

**部位倍率**: 正面 1.0x, 侧面 1.2x, 背面 1.5x, 处决 固定值(无视防御)

### 格挡减伤

```
实际伤害 = 原始伤害 × (1 - 格挡减伤率)
```

- 普通格挡: 减伤 70%
- 精准格挡(弹反): 减伤 100% + 触发敌人硬直
- 格挡减伤率可被"竹简·法经"提升至 80%

### 韧性系统 (Boss/精英)

```
每次攻击减少韧性 = 伤害值
韧性归零 → 可处决状态 (2s)
韧性恢复速度 = 5/s (停止受击后2s开始恢复)
```

| 单位 | 最大韧性 | 恢复延迟 |
|---|---|---|
| 精英敌人 | 30 | 2.0s |
| 韩弩将军 | 50 | 2.5s |
| 赵盾之灵 | 80 | 2.5s |
| 魏武卒魂·统帅 | 120 | 3.0s |
| 楚巫祭·灵均 | 60 | 2.0s |
| 荆轲执念 | 40 | 1.5s |
| 稷下魂·辩论 | 无 | — |
| 嬴政·肇始 | 100/80/无 | 3.0s/2.0s/— |

### 处决伤害

```
处决伤害 = 目标最大HP × 30% (最低50)
处决回复 = 10 HP
```
